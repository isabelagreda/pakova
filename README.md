# Pakova · Sitio web

Sitio estático de Pakova, una asociación civil de Rosario dedicada a la formación tecnológica gratuita.

## Estructura

- `dist/index.html`: página principal.
- `dist/style.css`: estilos y diseño responsive.
- `dist/app.js`: navegación móvil y enlaces de contacto.
- `dist/assets/`: logo, fotografías y recursos visuales tomados de la web actual de Pakova.
- `.openai/hosting.json`: configuración de publicación en Sites.

## Ver localmente

Abrí `dist/index.html` en el navegador o ejecutá un servidor local desde la carpeta `dist`.
